# fronte-meridionale-miniapp
Mini App Telegram del progetto Fronte Meridionale.  Interfaccia principale per l’onboarding degli utenti, il collegamento del wallet TON e la gestione dello stato membro tramite transazioni blockchain.  L’app consente agli utenti di entrare nel sistema, ottenere un codice membro e partecipare in modo trasparente e verificabile.
